Realtime Chat App

🚀 Overview

A Realtime Chat App built with MERN Stack and Socket.io for instant messaging. The app features authentication & authorization with JWT, real-time messaging, online user status, and state management using Zustand. The app is styled with TailwindCSS and Daisy UI, providing a sleek and modern UI.

🌟 Tech Stack

Frontend: React.js, TailwindCSS, Daisy UI, Zustand

Backend: Node.js, Express.js, MongoDB, JWT Authentication

Realtime Communication: Socket.io

Deployment: Render (Free hosting)

🎯 Features

🔑 Authentication & Authorization (JWT-based login & signup)

💬 Real-time messaging powered by Socket.io

🟢 Online user status tracking

⚡ Global state management with Zustand

🛡️ Secure API endpoints with JWT authentication

🚀 Error handling on both client and server sides

🌍 Responsive UI with TailwindCSS & Daisy UI
